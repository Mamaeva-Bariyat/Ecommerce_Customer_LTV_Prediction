# 📈 Прогнозирование LTV клиента (пожизненная ценность)

Проект по прогнозированию **Lifetime Value (LTV)** клиентов на основе данных интернет-магазина (Olist, Бразилия). 
Цель — сегментировать клиентов по потенциальной ценности и предложить стратегии удержания.

## 🎯 Описание задачи
**Lifetime Value (LTV)** — суммарная выручка, которую клиент принесёт компании за всё время взаимодействия.
Проблема e-commerce: 95–99% клиентов делают одну покупку, повторные крайне редки. Нужно предсказать вероятность возврата и оценить будущую ценность.

## 🛠 Что сделано в проекте
1. **Предобработка** (1.LTV_Preprocessed_data.ipynb): очистка данных, обработка пропусков.
2. **EDA** (2.EDA — Exploratory Data Analysis.ipynb): анализ статусов заказов, географии, категорий.
3. **RFM и кластеризация** (3.Геокластеризация, отзывы и RFM.ipynb): расчёт RFM-метрик, сегментация (Champions, Loyal, At Risk), гео-кластеризация.
4. **Feature Engineering** (4.Feature Engineering.ipynb): кодирование RFM, One-Hot географии, создание признаков, обработка выбросов.
5. **Моделирование** (5.Моделирование LTV.ipynb): бинарная классификация возврата (XGBoost + LightGBM + CatBoost), StratifiedKFold (5 фолдов), балансировка классов. LTV = Вероятность возврата × Средний чек (~140 R$). Сегментация на 10 децилей.

## 📊 Ключевые результаты
- **ROC-AUC**: ~0.82 – 0.89 (средний ~0.826)
- **Средний предсказанный LTV**: ~11–15 $
- **Лучшие сегменты**: Децили 8–10 (LTV 80–123 R$) — приоритет для акций.

### 💡 Рекомендации по децилям LTV
| Группа | Средний LTV | Доля | Рекомендация |
| :--- | :--- | :--- | :--- |
| **1–3** | ~0.02 R$ | ~75% | Минимальные усилия: общие рассылки 1 раз в квартал |
| **4–7** | ~46.83 R$ | ~25% | Персонализация + скидка 15% |
| **8–10** | ~80–123 R$ | <1% | Максимум внимания: индивидуальные предложения, VIP |

## 🚀 Установка и запуск
1. **Клонирование**: `git clone git@github.com:Mamaeva-Bariyat/Ecommerce_Customer_LTV_Prediction.git && cd Ecommerce_Customer_LTV_Prediction`
2. **Окружение**: `python3 -m venv venv && source venv/bin/activate && pip install -r requirements.txt`
3. **Данные**: Установите Kaggle CLI, добавьте `kaggle.json` и запустите `python download_data.py`
4. **Запуск**: `jupyter notebook` (выполняйте ноутбуки по порядку от 1 до 5)
